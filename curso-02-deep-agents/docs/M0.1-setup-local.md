# M0.1 · Setup local con Ollama

> **Estado:** ✅ · **Fecha:** 2026-10-06 · **Lab Python:** `python/models.py` + `python/local_model.py`

## 🧸 La idea en simple
Todos los labs del curso sacan su modelo de **un solo archivo**: `python/models.py`. Si cambiamos ese archivo, cambia el modelo de todo el curso sin tocar ningún lab. Es como cambiar el **motor** de un carro sin cambiar la carrocería.

## 📚 Conceptos clave
- **`models.py`:** exporta `model` (el rápido) y `strong_model` (el que razona mejor). Los labs hacen `from models import model`.
- **`local_model.py`:** helper que crea un `ChatOllama` apuntando al servidor de la LAN, leyendo la URL del `.env`.
- **`load_dotenv(override=True)`:** en este curso el `.env` **gana** sobre las variables del sistema.

## 🧪 Resultado
```text
$ uv run python -c "from models import model, strong_model; print(model.base_url); print(model.invoke('di hola en 3 palabras').content)"
http://<ollama-host>:11434
Hola, ¿qué tal?
```

| Rol | Original | Local |
|---|---|---|
| `model` | `anthropic:claude-haiku-4-5` | `gemma4:latest` (`num_ctx` 16k) |
| `strong_model` | `anthropic:claude-sonnet-4-6` | `qwen3:8b` (`num_ctx` 32k) |

## 🛠️ Problema → causa → solución → regla
| # | Problema | Causa | Solución | Regla |
|---|---|---|---|---|
| 1 | `'ChatAnthropic' object has no attribute 'base_url'` | `models.py` seguía con la versión original | Reescribir `models.py` y verificar el tamaño del archivo | Después de editar, **verifica** que el cambio quedó (`grep`, tamaño) |
| 2 | Riesgo de quedarse corto de contexto | El system prompt de Deep Agents es largo (planning + filesystem + subagents) | `num_ctx` por defecto en 16k, y 32k para el modelo fuerte | Con deep agents, sube `num_ctx` antes de culpar al modelo |

## 🎯 Para el examen
- `init_chat_model("proveedor:modelo")` es la forma agnóstica del proveedor; cambiar de proveedor = cambiar el string o la clase.
- Deep Agents acepta cualquier chat model de LangChain que soporte **tool calling**.
