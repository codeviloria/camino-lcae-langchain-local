# Examen LCAE — Guía

## Formato
- 40 preguntas de selección múltiple · **28/40 para aprobar (70%)**
- 120 min (~135 min de sesión total) · solo en inglés
- Online, supervisado en vivo (Talview), individual
- Se aprovisiona una organización LangSmith dedicada para la sesión
- Precio: USD 99 · vigencia 24 meses
- Soporte: certification-support@langchain.dev
- Aprobar los cursos **no** otorga la certificación; el examen se compra aparte.

## Semi open-book
✅ Permitido: smith.langchain.com · docs.langchain.com · academy.langchain.com
❌ Prohibido: buscadores, asistentes IA (ChatGPT, Claude…), segunda pantalla, comunicación externa, automatización de navegador.
> Implicación: saber **dónde** está cada cosa en docs/Academy vale tanto como memorizarla. Anotar rutas de docs en cada lección.

## Dominios (25% c/u, 10 preguntas c/u) — organizados según el ADLC (Agent Development Lifecycle)

### 1. Build → cursos 01 y 02
- [ ] Diferencias entre `create_agent` y `deepagents`
- [ ] Middleware
- [ ] Context engineering para agentes de larga duración
- [ ] `AGENTS.md` y `SKILL.md`
- [ ] Sandboxing

### 2. Test → curso 03
- [ ] Evaluadores basados en código vs LLM-as-judge
- [ ] Evaluación online vs offline
- [ ] Ejecutar experimentos e interpretar resultados
- [ ] Alineación de evaluadores
- [ ] Gestión de ejemplos de datasets

### 3. Deploy → curso 05
- [ ] Terminología: graph, deployment, revision, assistant, thread, run
- [ ] Serving multi-región
- [ ] Gestión de secretos
- [ ] Autenticación vs autorización
- [ ] Durabilidad del almacenamiento

### 4. Monitor → curso 04
- [ ] Leer e interpretar traces
- [ ] Organización de traces por thread
- [ ] Atribución de costos y sentimiento de usuario
- [ ] Online Evals vs Insights
- [ ] Alertas
