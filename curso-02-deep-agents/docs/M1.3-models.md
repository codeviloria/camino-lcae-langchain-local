# M1.3 · Models

> **Estado:** ✅ · **Fecha:** 2026-10-06 · **Lab:** `python/m1/m1.2_scratch_agent.py` (mismo lab, otro modelo) · **Modelos:** Nemotron 3 Ultra 550B, LFM 2.5 2.6B, Gemma 4 31B (OpenRouter `:free`)

## 🧸 La idea en simple
El agente es el coche y el modelo es el motor. `init_chat_model("proveedor:modelo")` es un enchufe estándar: cambias el prefijo y cambias de proveedor, cambias el sufijo y cambias de modelo. El agente, el system prompt y las tools no se enteran.

## 📚 Conceptos clave
- **`init_chat_model("anthropic:claude-haiku-4-5")`**: un string elige proveedor + modelo. LangChain soporta 50+ proveedores.
- Todos los labs importan `model` desde **`models.py`**: un solo punto de cambio. Aquí, además, el interruptor `MODEL_PROVIDER` y `OPENROUTER_MODEL` en el entorno.
- **3 categorías del curso:** propietarios conversacionales (Haiku, GPT-4.1), razonamiento avanzado (Opus, o3) y open-weight (Llama, Qwen, Mistral).
- Open-source: privacidad (local), costo, sin *vendor lock-in*, fine-tuning. Modelos chicos pueden fallar en tool calling o ignorar el system prompt.
- `:free` en OpenRouter = el proveedor puede usar tus prompts para entrenar. Nada sensible.

## 🧪 Resultado

|---|---|---|

## 🛠️ Problema → causa → solución → regla
| Problema | Causa | Solución | Regla |
|---|---|---|---|
| `429 temporarily rate-limited upstream` | Los `:free` comparten cupo entre todos los usuarios | Reintentar más tarde o probar otro `:free` | Con modelos gratis, el fallo puede ser de cupo y no de tu código |
| `429 Rate limit exceeded: free-models-per-day` al cerrar el módulo | Cuenta sin créditos = **50 requests gratis al día** (se reinicia a las 00:00 UTC). Un deep agent hace varias llamadas al modelo por cada `invoke` | Esperar al reinicio, cargar 10 créditos (sube a 1000/día) o usar Ollama local | Presupuesta las llamadas: ~1 módulo de labs por día con la cuenta gratis |
| `503 provider_overloaded` (varios labs) | NVIDIA saturado. OpenRouter lo devuelve dentro de la respuesta y `langchain_openai` lanza `ValueError`, así que `max_retries=2` **no** reintenta | Volver a correr el lab (o correr menos labs en paralelo) | `max_retries` solo cubre errores HTTP, no errores que llegan en el cuerpo |

## 🎯 Para el examen
- Cambiar de modelo = cambiar **una línea** (`models.py`). El system prompt y las tools no cambian.
- Trampa: creer que el formato es `"claude-haiku-4-5"` solo. Va con prefijo: `"anthropic:claude-haiku-4-5"`.
- Azure, Bedrock y Google requieren un *extra* (`uv sync --extra ...`). Anthropic, OpenAI y Ollama ya vienen.

## 🧠 Mnemotecnia
**"Prefijo = quién, sufijo = cuál":** `proveedor:modelo`.
